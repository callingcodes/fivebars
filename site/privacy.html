Privacy

Fivebars collects no personal data. There is no account and no tracking, and update checks are counted anonymously.

What it sends

One ICMP echo request (a ping) per second to the host you set in Settings, 1.1.1.1 by default. If you enter a host name, your Mac's usual DNS resolver looks up its address. Apart from the update check below, Fivebars makes no other network connections: no crash reports, no telemetry.

Update checks

Once a day, Fivebars asks callingcodes.com whether a newer version exists. The request carries the Fivebars, Sparkle (its update framework) and macOS versions and, like any web request, your IP address. We store no IP address and no identifier; we keep only daily counts of checks and downloads per app version, macOS version and country. Updates also download from callingcodes.com. Cloudflare, Inc. hosts the site and processes these requests for us.

Fivebars asks before it installs an update, unless you turn on automatic installs. You can turn off automatic checks in Settings.

What it keeps

Your settings are stored in macOS user defaults. All-time statistics (pings sent, replies, losses, average, fastest and slowest times, per host) are saved in a file in your Application Support folder. Both stay on your Mac. Session statistics live in memory and disappear when you quit.

Notifications

Connection Down and Connection Up alerts are local macOS notifications. They are off by default and nothing about them leaves your Mac.

This website

This page loads its fonts from Google Fonts. It sets no cookies; it only remembers your light or dark theme choice in your browser.
