Fivebars 1.1

  • A new menu. Fivebars now opens a single native menu from the menu bar, translucent like the system's own, on left or right click. The separate right-click menu is gone.
  • Clearer chart. The 5-minute chart uses wider bars, each coloured by its worst moment: green, orange when slow, red when lost.
  • Choose how often to ping. Set any interval from 1 to 60 seconds in Settings. The quality score adapts so the bars stay meaningful at slow intervals.
  • Packet loss, only when it matters. Show it Off, When There's Loss or Always. When There's Loss is the new default.
  • Tighter menu bar item. Less empty space next to the packet loss percentage.
  • Closes like a menu. Click anywhere else or press Esc.
